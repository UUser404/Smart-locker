# Smart-dispenser
Smart Dispenser adalah dispenser minuman otomatis berbasis IoT menggunakan ESP32 dengan 3 pilihan rasa. Pengguna dapat memilih rasa dan mengontrol pompa melalui smartphone tanpa aplikasi, cukup terhubung ke WiFi dispenser. Proyek ini dikembangkan sebagai sarana belajar IoT dan elektronika untuk penggunaan di berbagai acara.
